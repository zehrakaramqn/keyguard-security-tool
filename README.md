# 🔐 KeyGuard: Password Security & AES-256 Suite

KeyGuard, kullanıcıların oluşturduğu parolaların siber güvenlik standartlarına (uzunluk, karakter çeşitliliği) uygunluğunu analiz eden ve hassas metinleri **AES-256** algoritmasıyla şifreleyip **SHA-256** hash değerlerini türeten açık kaynaklı bir Python uygulamasıdır.

## 🚀 Özellikler
* **🛡️ Parola Güvenlik Analizi:** Parolaların karmaşıklığını ölçer ve anlık tavsiyeler sunar.
* **🔒 AES-256 Şifreleme:** Gizli mesajları anahtar (passphrase) ile şifreler ve çözer.
* **🔑 SHA-256 Hashing:** Metinlerin veri bütünlüğünü doğrulamak için hash üretir.
* **🌐 Şık Web Arayüzü:** Streamlit kütüphanesi ile hızlı ve kullanımı kolay panel.
